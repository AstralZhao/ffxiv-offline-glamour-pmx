# 幻衣间 Demo

双击项目根目录的 **启动试衣客户端.cmd** 或 **启动试衣Demo.cmd**。默认打开原生Windows客户端，不需要启动游戏或本机网页服务。使用本机已有的Python、Tk、NumPy、Pillow和Windows Direct3D 11环境；暂未打包为可脱离这些本机依赖的独立EXE。

D3D11在客户端原生窗口里直接显示，模型帧不经过GPU读回、PNG编码、HTTP传输或网页画布。原始材质先绘入FP16目标，最后在GPU上转换到窗口交换链。窗口大小改变时重建显示目标，保持原始材质流程。静态角色只在视角、尺寸或搭配改变时重绘，连续拖动会合并到最新相机状态，不排队播放过时视角。

默认包含你的`test.dat`，首次启动会复制到软件根目录的`presets/test.dat`。预设列表只使用软件目录中的副本；角色卡片右侧的导入按钮会新建一份原生`.dat`副本，同名自动另存。游戏里的原文件保持只读。

如果预设文件已导入但对应模型暂时无法加载，会保留文件和原画面，并提供编辑新文件的入口；可以先修改、保存，再单独更新模型。文件格式错误仍会明确拒绝导入。

点击“编辑发型与捏脸”，可修改发型、脸型、五官、身高、胸围、尾巴、颜色和彩绘等。“更新模型”只预览修改，不改所选DAT；“保存预设”只写入当前软件DAT，不更新画面。两项操作相互独立，界面会提示模型与文件是否一致。更新模型后会关闭窗口方便观察，再打开时保留尚未保存的预览。装备、染色和相机继续保留。首次生成新外观需要稍等；未能生成时保持原模型和文件。两个部族均可尝试；发型列表来自国服创建菜单，未知可见结构仍会提示原因。

- 按部位搜索装备名称或编号，双击同模目录，再双击款式试穿。目录全量开放，没有已验证装备白名单，不限制获取、职业和等级。
- 装备按同一部位、同一基础模型编号归为同模目录。目录名称和原始游戏图标采用整组中染色区最多的装备；数量相同时优先较新的装备编号。点击目录选择具体款式，返回时保留原搜索、已加载的分页和进入前的滚动位置。
- 点击装备换装，点击装备下的两个色块分别染色。区域数量及染剂名称来自国服本机数据。
- 左键拖动旋转和俯仰，右键拖动平移，滚轮缩放；工具栏可切正面、侧面、背面或还原相机。
- 保存搭配后，可从“我的搭配”重新试穿。文件保存在`artifacts/demo`，不会改动游戏角色或安装目录。
- 武器不在软件范围内。

当前目录有20,519件防具和饰品。所有条目都可以发起共用渲染，部分特殊材质、骨架驱动和遮盖组合仍未实现；遇到这些情况会保留上次成功画面并显示原因。目录开放不代表每件装备均已成功绘制。

这些条目归为5,211组模型目录，左右戒指共用款式来源。搜索任何成员名称或编号都能找到所属目录，目录代表不会随搜索结果改名。原色变体和染色能力仍按具体装备保留。

防具和饰品共享本机EQDP模型选择与PBD逐层变形路径；不会因为共用模型来自其他基础体型就一律拒绝。没有本机资源或仍缺少实现的结构会明确提示。

头饰、衣服可按EST加载原始额外骨架，并连接到预设的固定站姿。变形缺少某个额外关节时，沿文件中的真实父级继承，不按名称猜测或填单位矩阵。头饰固定使用原始闭合面罩参考状态；本版没有面罩切换、衣物摆动或装备物理动画。身体遮盖头部和高领遮盖头甲护颈也接入共用规则。

已接入滚动纹理、丝袜和玻璃三类原始着色程序：滚动纹理保持固定时间；丝袜读取额外的贴图坐标和原生皮肤材质；玻璃在不透明部件之后合成透射颜色与反射。它们仍使用原始染色表。当前是固定预览条件下的实现，尚未完成这些材质与游戏画面的逐项一致性确认。

普通半透明材质与`charactertransparency`使用原始颜色/透明度输出，在不透明部件之后排序合成；头发继续保留原有的主体和发梢两段流程。装备中的纹身、遮蔽材质复用既有叠加通道。相机会为翅膀等实际可见的大体积装备扩大取景，缩放范围为0.25至4倍。

装备贴花按原生IMC编号读取，使用独立的中性颜色乘数，不继承脸部彩绘颜色。头发按国服帽下发型模式控制，分别隐藏头顶、后发或全部头发，并应用原始帽下形变。预览处于未骑乘的固定站姿，因此坐骑EVP效果抑制标记不会阻止装备加载。

腰部、腿部护片、靴筒和护膝的遮盖按国服客户端条件组合，使用原始`shp_kos`、`shp_sho`等形变；尾部开口按预设种族筛选。长衣与裤靴搭配不会再因为腿部护片标记而一律拒绝。

高领与头盔护颈、手套与上衣袖口按国服成组优先级和部位开关取舍；连体衣自身也会响应靴筒裁切。处理原始部件属性及模型形变，不改模型尺寸来掩盖交叠。

完全被装备遮住的饰品保留选择和染色，暂不加载绘制资源；脱下遮盖装备后自动恢复显示。已经隐藏的子网格上有形变重叠时，也不会再阻止整个搭配。

连体衣遮住的防具、关闭显示的头饰也只保留选择与染色，不准备不可见模型和材质；仍会检查装备部位及染色是否合法。重新显示时恢复完整加载。隐形装备继续使用原始身体/内衣与占位网格，不一律当成空模型。

多个装备遮盖规则同时改变同一位置时，按原始模型文件中的形变顺序组合，后面的替换覆盖前面的；不再因为可见形变重叠而直接拒绝搭配，也不依赖试穿的先后顺序。

少量装备引用的可选材质动画文件在本机不存在时，允许显示原始静态材质，并在预览下方提示。实际存在但尚未解读的动画文件仍会明确报错；这不代表已经实现材质动画播放。

当前统一关闭装备的附加粒子特效，只显示原始装备模型和材质，带特效的装备也可以正常试穿主体。特效读取和部分绘制代码保留供后续完善，完整实现后再提供显示开关；现阶段不需要加载AVFX或等待特效验证。

预览使用真实模型、骨架、原始材质与现有国服独立D3D11渲染流程。模型和骨架驻留并复用；未提供动作、表情或姿势编辑。客户端记录上次预设、已绘制但未保存的外观、搭配及相机；文件被外部修改时加载实际新文件，不自动覆盖。此原型不代表第四阶段或全部装备外观还原已完成。

如需指定其他目录，可运行：

```powershell
& 'G:/Tools/Anaconda3/python.exe' -X utf8 demo/client.py --game '游戏安装目录' --preset '外观预设.dat'
```

关闭客户端会先结束当前GPU操作再释放窗口资源。日志在`artifacts/demo/demo.log`；所有导入副本和搭配都留在项目内。旧网页原型仍可手动运行`demo/app.py`，保留作兼容入口；客户端本身不启动或依赖该服务。文件保存保留SHA冲突检查。
