# 幻衣间 Demo

双击项目根目录的 **启动试衣Demo.cmd**。会打开独立的本机试衣窗口，不需要启动游戏。当前使用本机已有的Python、NumPy、Pillow和Windows Direct3D 11环境。

可以直接使用已保存的敖龙族女性预设，或点击角色卡片右侧的导入按钮选择原生`.dat`文件。两个部族均可尝试；未知预设结构会提示原因。

- 在防具、饰品分类中搜索装备名称或编号。目录全量开放，没有已验证装备白名单，不限制获取、职业和等级。
- 点击装备换装，点击装备下的两个色块分别染色。区域数量及染剂名称来自国服本机数据。
- 左键拖动旋转和俯仰，右键拖动平移，滚轮缩放；工具栏可切正面、侧面、背面或还原相机。
- 保存搭配后，可从“我的搭配”重新试穿。文件保存在`artifacts/demo`，不会改动游戏角色或安装目录。
- 武器不在软件范围内。

当前目录有20,519件防具和饰品。所有条目都可以发起共用渲染，部分特殊材质、骨架驱动和遮盖组合仍未实现；遇到这些情况会保留上次成功画面并显示原因。目录开放不代表每件装备均已成功绘制。

防具和饰品共享本机EQDP模型选择与PBD逐层变形路径；不会因为共用模型来自其他基础体型就一律拒绝。没有本机资源或仍缺少实现的结构会明确提示。

头饰、衣服可按EST加载原始额外骨架，并连接到预设的固定站姿。变形缺少某个额外关节时，沿文件中的真实父级继承，不按名称猜测或填单位矩阵。头饰固定使用原始闭合面罩参考状态；本版没有面罩切换、衣物摆动或装备物理动画。身体遮盖头部和高领遮盖头甲护颈也接入共用规则。

预览使用真实模型、骨架、原始材质与现有国服独立D3D11渲染流程。相机改变后在三维场景重新绘制，通过本机连接更新交互画布。模型和骨架驻留并复用；未提供动作、表情或姿势编辑。此原型不代表第四阶段或全部装备外观还原已完成。

如需指定其他目录，可运行：

```powershell
& 'G:/Tools/Anaconda3/python.exe' -X utf8 demo/app.py --game '游戏安装目录' --preset '外观预设.dat'
```

同一本机服务运行时，重新双击启动文件会打开已有试衣间。可在“原型说明”中关闭服务。日志在`artifacts/demo/demo.log`；所有导入副本和搭配都留在项目内。
